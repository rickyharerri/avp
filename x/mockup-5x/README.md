# AVP Wedding Photography Website

This recreation is based on the supplied reference image.

## Files
- `index.html` — page markup
- `style.css` — visual styling and fixed-canvas scaling
- `script.js` — viewport fitting and form demo behavior
- `assets/` — image crops taken from the supplied reference

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

The layout uses a 1440 px design canvas and scales down proportionally so the supplied 366 × 800 reference composition is preserved.
